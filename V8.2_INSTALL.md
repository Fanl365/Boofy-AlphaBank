# Boofy AlphaBank V8.2 — clean install

V8.2 fixes the Vite peer dependency conflict in V8.1.

Required Node versions:
- Node 20.19+ (20.x), or
- Node 22.12+ / newer

From a fresh V8.2 folder:

```bash
node -v
npm -v
npm install
npm start
```

If you are reusing an older V8/V8.1 folder, clear the old install state first:

```bash
rm -rf node_modules package-lock.json
npm cache verify
npm install
npm start
```

Do not use `--force` or `--legacy-peer-deps` for V8.2.
